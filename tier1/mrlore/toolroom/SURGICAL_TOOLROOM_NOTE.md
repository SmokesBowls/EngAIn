# MrLore Surgical Toolroom Note

Status: boundary note only.

This toolroom intentionally starts empty after Tier1 staging.
Old production-era `_mrlore/tools/` files are not active here and must not be copied here.
If old tools are preserved, they belong only under `tier1/mrlore/archive/old_tools/` as evidence/history.

Rules:

- No old tool becomes active by being copied.
- No old tool decides canon.
- No old tool dispatches runtime.
- Surgical analysis tools are created only after the staged Tier1 tree passes proof gates.
- New production tools are created later after surgical proof gates and explicit approval.
