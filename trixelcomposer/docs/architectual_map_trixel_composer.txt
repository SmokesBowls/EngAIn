### ⚡ The One Integration Gap
`empire_bridge.py` expects these methods on the attached composer:
```python
composer.perceive()   → returns canvas + state dict
composer.plan()       → returns action dict
composer.act(plan)    → executes action
composer.tool         → current tool string
composer.canvas       → grid reference
```

But the two composers name them differently:
| Composer | Planning Method | Execution Method |
|----------|----------------|------------------|
| `terminal_trixel.py` | `plan_action(perception)` | `execute_action(action)` |
| `enhanced_trixel_core.py` | `_autonomous_plan(perception)` | `_execute_action(action)` |

**Fix (drop-in adapter):**
```python
def _bridge_adapter(composer):
    composer.act = lambda plan: composer.execute_action(CreativeAction(**plan)) if hasattr(composer, "execute_action") else composer._execute_action(CreativeAction(**plan))
    composer.plan = lambda: composer._autonomous_plan(composer.perceive()) if hasattr(composer, "_autonomous_plan") else composer.plan_action(composer.perceive())
    return composer
```
Attach it before the bridge:
```python
composer = TerminalTrixelComposer()  # or EnhancedTrixelComposer()
_bridge_adapter(composer)
composer = attach_empire_bridge(composer)
```
