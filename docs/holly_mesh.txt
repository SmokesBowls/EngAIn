Looking at your screenshots and understanding the context - you have assets appearing at runtime (30 blue capsules from semantic bridge), but they're spawned dynamically and can't be edited in the Godot editor.

The Core Problem:
Runtime-spawned nodes don't exist in the scene tree until the game runs, so the Inspector can't edit them. This is the standard Godot limitation.

The Solution: Make Runtime Entities Inspector-Editable

Option 3: Snapshot-Driven Scene Generation
Most powerful but complex - generate .tscn files from vault data:

python
# scene_builder.py
def generate_scene_file(entities):
    """Convert vault entities → .tscn file"""
    tscn = f"""[gd_scene load_steps=2 format=3]
    
[node name="GeneratedScene" type="Node2D"]

"""
    for entity in entities:
        tscn += f"""
[node name="{entity.name}" type="Sprite2D" parent="."]
position = Vector2({entity.x}, {entity.y})
"""
    return tscn
Call this from Trae when vault changes, then Godot reloads the scene automatically.

import requests

def spawn_entities():
    snapshot = requests.get("http://127.0.0.1:8080/snapshot").json()
    
    for entity in snapshot["bridge_entities"]:
        # Spawn Blender object
        scene = logic.getCurrentScene()
        obj = scene.addObject("EntityTemplate", "Root")
        obj.worldPosition = entity["position"]
        obj["vault_id"] = entity["id"]
        obj["name"] = entity["name"]
