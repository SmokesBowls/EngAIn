# Trixel 1st Lane Asset Authority Instructions

This lane contains Trixel asset-authority work.

Trixel is TIER1 authority for art/asset truth.

Trixel is not under EngAInOS production authority.

This lane owns:

- asset IDs
- atlas IDs
- tile variants
- meshes
- skins
- sprites
- visual recipes
- asset manifests
- asset provenance
- asset supersession
- internal Trixel lane order

This lane does not own:

- EngAIn declared scene truth
- EngAIn declared entity truth
- EngAIn runtime acceptance
- MrLore canon/lore truth
- GodotSim simulation execution
- Godot presentation

If a Trixel worker does not know what lane it is in, work must stop.

Unknown lane state is:

BLOCKED_PENDING_TRIXEL_TIER1_LANE_ASSIGNMENT

The worker must ask Trixel TIER1 before continuing.
