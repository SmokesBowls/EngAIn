# TIER vs Lane Rule

TIER means system-wide authority rank.

Lane means ordered work boundary.

A TIER folder defines who owns authority.

A lane folder defines how work must stay inside its boundary.

TIER folders do not replace lane folders.

Lane folders do not replace TIER folders.

If a worker does not know what lane it is in, it must stop and ask the owning TIER1 authority.

Inside EngAIn declared/runtime truth, the owning TIER1 authority is EngAInOS.

Inside Trixel art/asset truth, the owning TIER1 authority is Trixel.

Do not move folders until both the TIER authority map and the lane instructions exist.

TIER1 systems cannot overrule each other.
They must only agree.

This gives us the governing rule for the contracts:

TIER = who may decide.
Lane = where the work is allowed to happen.
Cross-TIER1 boundary = agreement required.
No agreement = fail closed.

That is the foundation.
