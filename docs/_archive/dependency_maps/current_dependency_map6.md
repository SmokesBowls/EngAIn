## 3. Compiled Ingestion & Mirror Layer (`.engain/`)

Automated output target directory containing normalized structures compiled directly from the markdown sources.

### [ZONJ Scene Envelopes (.engain/build/)](file:///home/mytruelove/Downloads/obsidianburdenNov25/.engain/build/)
* **Directory Path:** `/home/mytruelove/Downloads/obsidianburdenNov25/.engain/build/book01_garden_genesis/scenes/`
* **Role:** Decoupled game scene blueprints in ZONJ (JSON) format. Houses the fully-realized semantic game data (injected entities, normalized positions, environment markers, dialog arrays, and random seeds) parsed from story books.
* **Imports/Calls:** `ingest_manifest.json` (parent manifest tracking segment translation stats).
* **Called By:** Evaluated at runtime by the simulation server (`godotsim/sim_runtime.py` and `godotsim/scene_manager.py`) during `POST /scene/load` calls to populate the `snapshot["scene_raw"]` array.
* **Hardcoded Paths:** None (self-contained JSON schemas).
* **Safe to Move:** **Yes** (These are generated output cache files that are easily regenerated by triggering the `mettaext` pipeline).
* **Notes:** Individual scenes correspond to chapters (e.g. `zonj_01_the_ethereal_vigil.json` maps directly to `001_the_ethereal_vigil.md`).
